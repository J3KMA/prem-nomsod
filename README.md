# 🥛 เปรม นมสด (Prem Nomsod) - Landing Page

เว็บไซต์ Landing Page ทางการของร้าน **"เปรม นมสด"** ร้านนมสด ขนมปังปิ้งเตาหอม ปังเย็น และของทานเล่นยามค่ำคืน

---

## 🌟 ฟีเจอร์เด่น (Key Features)

* **Mobile-First & Fully Responsive:** ออกแบบรองรับการใช้งานบนสมาร์ตโฟน แท็บเล็ต และคอมพิวเตอร์อย่างลื่นไหล พร้อม Mobile Bottom Navigation Bar
* **Live Opening Status:** ระบบตรวจสอบเวลาเปิด-ปิดร้านแบบเรียลไทม์ (เปิดบริการทุกวัน 17:00 – 22:00 น.) พร้อมไฟสถานะไดนามิก
* **Interactive Menu Tabs:** ระบบกรองดูหมวดหมู่เมนู (เครื่องดื่มนมสด, ขนมปังปิ้ง & ปังเย็น, ของทานเล่น)
* **Photo Gallery & Lightbox:** รวมภาพบรรยากาศร้านยามค่ำคืน พร้อมโหมด Lightbox ดูภาพขยายใหญ่ระดับ HD
* **Direct Social & Map Links:**
  * Facebook: [fb.com/premnomsod](https://www.facebook.com/premnomsod/)
  * Google Maps: [นำทางมาร้าน](https://maps.app.goo.gl/D74mjjUod8oMfGfr5)

---

## 🛠️ เทคโนโลยีที่ใช้ (Tech Stack)

* **HTML5 & Semantic Markup**
* **Tailwind CSS (CDN)** - สำหรับการจัด Layout และดีไซน์ที่ทันสมัย
* **Lucide Icons** - ไอคอนเวกเตอร์คมชัด
* **Google Fonts (Kanit & Prompt)** - ฟอนต์ไทยที่อ่านง่ายและสวยงาม

---

## 🚀 การติดตั้งและเปิดใช้งาน

สามารถดาวน์โหลดหรือ Clone โปรเจกต์ แล้วเปิดไฟล์ `index.html` ผ่านเว็บเบราว์เซอร์ได้ทันทีโดยไม่ต้องลงเซิร์ฟเวอร์
